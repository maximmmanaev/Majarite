# QuoteFlow

QuoteFlow is a service configuration and quoting platform for freelancers, agencies, consultants, integrators, and small service businesses.

## Core idea

QuoteFlow turns a client's need into a structured service configuration, scope, estimate, and quote.

The product is not a CRM and not an invoicing system. Its core responsibility is the stage before a quote is created:

`Need -> Questions -> Requirements -> Rules -> Scope -> Estimate -> Quote`

## MVP focus

- Service catalog
- Dynamic questionnaires
- Rule-based configuration
- Scope generation
- Pricing and estimate calculation
- Quote versioning
- Client approval
- Change Requests
- Audit/business events
- PostgreSQL as system of record
- REST API
- Docker Compose deployment

## Product principles

- Narrow B2B solopreneur product
- Rule engine first, AI optional
- Useful without AI
- Explicit business rules and traceability
- Integrate with CRM, payments, email, and messengers instead of replacing them
